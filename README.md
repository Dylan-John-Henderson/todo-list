# Todo List

A simple todo list app built with React and Vite, created as part of the Code the Dream React course. Currently displays a static list of todo items.

## Installation

```
git clone https://github.com/Dylan-John-Henderson/todo-list.git
cd todo-list
npm install
```

## Running the Development Server

```
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Built With

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
